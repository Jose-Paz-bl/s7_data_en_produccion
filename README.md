# s7_data_en_produccion
Este proyecto es para desplegar un análisis de datos en la web
El despliegue es acerca de un dataset relacionado con vehiculos
Se podrán encontrar diferentes gráficos relacionados con puntos claves del dataset tales como:
1. Condiciones de los vehiculos
2. Distribución de precios de los vehículos
3. Relación entre el precio y el millaje recorrido

Este proyecto tiene la única finalidad de hacer un rápido análisis exploratorio y despliegue en producción a través del servicio de streamlit: https://s7-data-en-produccion.onrender.com/
